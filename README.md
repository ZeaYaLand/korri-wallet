# Korri Wallet

Тёмный интерактивный UI-прототип криптокошелька на React, TypeScript и Vite.

## Запуск локально

1. Установи Node.js LTS.
2. Склонируй репозиторий или скачай его ZIP-архивом.
3. В папке проекта выполни:

```bash
npm install
npm run dev
```

4. Открой локальный адрес, который покажет Vite.

## Что есть в прототипе

- тёмный glassmorphism-интерфейс с фиолетовыми акцентами;
- демо-баланс и тестовые активы;
- скрытие и показ баланса;
- экран отправки с проверкой полей и симуляцией операции;
- экран получения с демонстрационным адресом;
- список демо-транзакций и вкладки приложения.

## Важно

Это только демонстрация интерфейса. Блокчейн не подключён, реальные транзакции не отправляются, ключи не создаются. Не добавляй в публичный репозиторий пароли, seed-фразы, приватные ключи или токены.
